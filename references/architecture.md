# 架构与边界

```text
用户需求 → WorkBuddy + SKILL.md → CLI → Node.js 服务 → SQLite
                                          ↑       ↓
                            本地查看页 ← 鉴权接口 → 浏览器侧栏
                                                     ↓
                                          用户授权的普通标签页
```

- `scripts/job-hunt.mjs` 是 WorkBuddy 入口，无需远程 MCP，不要求用户执行配对命令。
- `server/` 维护鉴权、任务、幂等、限速、计划、审阅及 SQLite，仅监听本机回环地址。
- `extension/` 使用已有会话，不启动浏览器，不读取 Cookie，不导出详情关联令牌；站点仍可能拒绝请求。
- `web/` 查看和修改草稿；凭据只在页内存，不写到 URL 或持久存储。
- `server/platforms.mjs` 注册平台能力；岗位键为 `平台:岗位ID`。猎聘与前程无忧尚需适配、权限和协议测试。

重启后已派发未确认动作记为不确定并暂停，避免重复外部动作。SQL 采用绑定参数；新增包含查询使用 SQLite `instr`，不用通配符模糊拼接。

代码和数据分离。数据库只保存白名单业务字段，不存原始响应、Cookie、认证令牌或请求头。正文和用户资料仍属私有数据。

本版不安装开机项/Windows 任务计划。关机、休眠或服务退出后无法采集。WorkBuddy 未运行时，待评分数据保留到下一次调用，不在后台自行唤醒 AI。

0.1.0 与旧个人版数据库不兼容，没有自动迁移。不要用旧数据库覆盖新库；未来迁移应先备份、校验版本，再逐字段导入。
